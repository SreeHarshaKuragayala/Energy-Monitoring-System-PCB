## Project Overview

The **Energy Monitoring System PCB** is an industrial-grade embedded hardware solution designed for real-time electrical energy monitoring across multiple channels. It enables IoT-based remote monitoring, power analytics, and energy optimization in industrial and institutional environments.

## Key Features

- ESP32-S3 high-performance microcontroller  
- Supports **10 CT Sensors** (multi-channel monitoring)  
- Real-time RMS, Power, and Power Factor calculation  
- Wi-Fi & Bluetooth connectivity  
- MQTT-based IoT communication  
- Buck converter based stable power architecture  
- Battery charging & backup support  
- Compact **2-layer industrial PCB**  

---

## Technical Specifications

| Parameter | Details |
|----------|---------|
| Microcontroller | ESP32-S3-WROOM |
| Flash | 16MB |
| PSRAM | 2MB |
| Communication | Wi-Fi + Bluetooth |
| Sensor Inputs | Up to 10 CT Sensors |
| Input Voltage | 5V |
| PCB Size | 118mm × 55mm |
| PCB Layers | 2 |
| Protocol | MQTT |
| Power System | Buck Converter + Battery Support |
